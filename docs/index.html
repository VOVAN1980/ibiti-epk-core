The problem

AI agents hold keys.
Keys get stolen.

Most "safe AI wallet" protection lives in the bot or on the server — exactly the parts that get hacked. When they fall, the money goes with them. EPK moves the rules into the vault, where a hacked server cannot switch them off.

A hacked server or agent

Prompt injection, malware or a leaked API key, and the agent signs whatever the attacker wants.

A stolen admin key

The worst case: the key that may change the rules is in the wrong hands.

One contract for everyone

Shared executors mean one mistake can reach every customer at once. EPK v2 gives each customer a separate vault.

The worst case

A stolen admin key, stopped in seconds.

Every change that could let money out has to wait in the vault's timelock, and any guardian may cancel it while it waits. The EPK Watchtower is a guardian that never sleeps.

  1. The thief uses the real admin key to schedule "allow payments to my address".
  2. The Watchtower cancels it 5 blocks later — no human involved.
  3. The thief tries to push it through anyway and the vault answers UnknownOperation: the change no longer exists.

How it works

Five layers between an attacker
and your funds.

Each layer works on its own. To take money, an attacker would have to beat all of them at once.

01

Your own vault

Every customer gets a separate vault at a permanent address. No shared contract, no shared risk.

1 vault per customerpermanent address
02

Limits and allowed addresses

Daily outflow limits per token, measured on the vault's real balance; money can only go to addresses on the vault's list; approvals cannot outlive a batch.

per-token limitsdestination listno lingering approvals
03

Agent sessions with budgets

AI agents get short sessions with their own budget and expiry, only for the calls the owner approved in advance.

own budgetexpiryapproved calls only
04

Guardians, timelock and panic

Tightening is instant; loosening waits in a timelock that any guardian can veto. One panic pauses everything and revokes every earlier permission.

≥ 2 guardianstimelockpanicrecovery key
05

Watchtower

An automatic guardian cancels any change the owner did not approve, presses panic on a burst of them and alerts the owner.

cancels in secondsalertscan't move funds

Upgrades without moving funds — only if the owner wants

New versions go through a public registry with a 7-day waiting window. A vault opts in through its own timelock (at least 2 days) that guardians can veto. Same address, same funds. Nobody — including IBITI Labs — can upgrade a customer's vault for them.

Built and checked like infrastructure

120 automated tests for the v2 vault alone (334 across the project), including fuzzing and stateful invariants (compromised operator, admin and session manager), Slither static analysis with every finding fixed or justified, four internal security reviews, verified source on BscScan.

Don't trust us

Check every claim yourself.
